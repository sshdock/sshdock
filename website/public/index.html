Your server.
Your decisions.

SSHDock is for a trusted owner running Compose apps on one VPS. You keep control of host maintenance, data consistency, availability, and recovery.

Read the operating boundary ↗
↳

One machine, understood.

Single-node deployment. Docker Compose owns the containers; Caddy handles HTTP routes.

↳

Recovery you choose.

No automatic rollback, migration reversal, or zero-downtime promise. Verify the result of each change.

↳

Data you look after.

Host-state archives and application-data backups are separate. Keep copies off-host and test restoration.
